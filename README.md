<img src="mobile/res/drawable-nodpi/aube_icon_original.png" width="128" alt="奥芙图标" />

## 功能

- 识别并购买誓约书签、神秘奖牌；检查顶部与底部商品。刷新返回后直接检查顶部，再滚动查找底部商品。
- 自定义两种资源的购买目标及最多刷新次数；两种购买目标均为 0 时只刷新。
- 购买前核对商品和价格，购买后结合对应行售罄及金币准确扣款确认成功；刷新后核对天空石扣款与返回商店。
- 只有核验成功才累计购买数量、金币和刷新计数。发出最终确认前保存待核验记录，结果不明确时停止，阻止直接重复开始。
- 奥芙悬浮人物：运行时跑动，等待时待机，结束或出错时摔倒；点击人物可展开控制面板并停止当前任务。
- 首次启动免责声明、启动页常驻声明及固定作者署名。清除应用数据或重新安装后可能重新显示首次声明。
- 手机版提供 **“检查画面（不刷新、不购买）”**，只读当前屏幕，不点击或滚动游戏。

## 使用前必须了解的消耗规则

默认设置是：**誓约书签 9999、神秘奖牌 9999、刷新次数 0**。

**刷新次数为 0 并不代表零消费！** 点击“开始”仍会扫描、购买当前批次中符合目标的商品，只是不进行付费刷新。首次检查请使用手机版的“检查画面”按钮。

- 购买目标按资源个数计算：书签每包 5 个、奖牌每包 50 个，整包购买可能使实际数量向上取整。
- 当前识别模板对应书签每包 184,000 金币、奖牌每包 280,000 金币、每次刷新 3 天空石；游戏价格或界面改变时应重新适配，不能凭本文假定新版本仍有效。
- 刷新次数是本次运行的上限。**应用没有单独的金币总预算输入框**，请按目标与余额自行控制；不要把最大目标 9999 当作消费预算。
- 出现待核验交易时先核对游戏实际余额和售罄状态。停止不能撤销已发送到游戏的购买或刷新，也不能保证网络延迟期间不会稍后扣款。

## 手机免 Root 版快速开始

1. 安装手机版 APK，阅读首次声明。
2. 从启动页进入系统设置，手动允许悬浮窗、开启“手机书签助手”无障碍服务。若系统对侧载应用限制无障碍，请按该系统的设置入口处理。
3. 点击“授权屏幕共享并开启悬浮窗”，授权**整个屏幕**。应用不申请录音权限；Android 的系统提示可能使用包含音频的通用措辞。
4. 打开**国服**游戏，横屏全屏进入秘密商店，停在商品列表顶部。首次授权后尚未开始任务/截图时，竖屏切换到横屏会保留未使用的授权。不要分屏、锁屏或同时使用其他点击工具。
5. 点击悬浮人物展开，先执行“检查画面（不刷新、不购买）”。未通过时不要开始运行。
6. 检查完成后共享已释放，先回启动页重新授权，再按自己的消费额度设置目标及刷新次数，点击“开始”。运行中保持游戏前台及亮屏。
7. 点击人物展开后停止，或使用通知栏停止。检查画面完成、任务完成/停止、离开游戏、锁屏，或任务/截图开始后旋转，会结束共享；再次运行需回启动页重新授权，不能复用旧授权。

原 Root 版需要手动授予悬浮窗与 Root 权限，使用实际截图 1280×720 的环境。它不提供手机版的只读“检查画面”按钮；不要用“刷新 0”替代零消费测试。

## 适配范围与已知边界

- 仅匹配国服包名 `com.zlongame.cn.epicseven` 和当前中文秘密商店布局，不支持国际服、日服、其他语言或其他游戏。
- 手机版按高度缩放居中商品区，分别匹配左右贴边的标题与余额。当前支持条件为横屏、约 16:9 至 2.8:1、有效高度至少 480 像素，并且校准通过；这不是任意分辨率兼容承诺。
- 已检查同一模拟器中 1280×720、1920×1080、2160×1080、2400×1080、2670×1200 的真实截图，以及包括 3200×1440、边缘偏移在内的合成重放。**这些不是对应手机的真机测试。**
- 4:3 平板、分屏、小窗、竖屏、未知布局未纳入验证。系统状态栏、导航栏、遮挡、异常黑边、显示缩放或游戏更新均可能使识别停止或失效。
- 无法识别余额、商品/价格不符、等待超时、前台游戏或窗口状态异常等情况会停止。相关检查可降低误操作风险，不能保证绝对准确、账号安全或防封。
- 国产系统的后台限制、无障碍受限设置与屏幕共享行为存在差异；Android 15/16、小米 14 及其他品牌的真机行为尚待验证。
- 悬浮人物、识别模板属于游戏相关素材，不代表取得游戏官方授权。免费、非商业和免责声明都不能代替授权。

## 权限与隐私

两版的 `INTERNET` 权限仅用于读取公开版本信息与公告；无云端用户账号、上传服务、广告或在线识别。屏幕仍在本机处理，任务状态保存在应用私有目录。通知查询代码独立放在私有 `:updates` 服务中；**普通独立进程共享应用 UID 和权限，这是代码隔离，不是系统级权限隔离，也不是只能收包的安卓权限。**

查询只向作者的 CNB 通知仓库固定文件发送 HTTPS GET，固定请求头，不发送屏幕、余额、联系人、文件、设备标识、已安装应用列表、当前版本、公告已读状态或任何请求正文。拒绝重定向和单文件超过16KiB的响应。托管平台及网络链路仍能获得IP等正常连接信息，不能宣传为“零网络元数据”。版本页面与APK链接仅限作者CNB通知仓库及GitHub源码仓库的对应发布标签、版本和包类型；下载交给用户浏览器完成，不在助手内下载或静默安装。

Root版在启动和每次读取完成后删除已知截图/命令临时文件；手机版只在核对游戏前台后请求一帧，用完断开画面Surface，停止/完成后释放共享。两版不再把运行余额日志写入系统logcat；必要的本机待核验记录仍保留。没有对外开放截图接口。

手机版使用悬浮窗展示操作入口；无障碍检查前台窗口并发送点击/滑动；MediaProjection 获取经用户授权的屏幕；前台服务和通知维持共享并提供停止入口。手机运行本身不需要电脑或 ADB。原版使用 Root，权限范围更大。

## 更新提醒、普通公告和手动检查

启动页显示当前版本，提供“手动检查更新和公告”、自动检查开关、“查看最近公告（本机缓存）”及源码仓库入口。自动检查默认开启，每24小时最多一次；可关闭后只使用手动检查。**这是打开助手时的提醒，不是后台推送。** 离开启动页或开启浮窗会取消两个请求，检查失败不会触发游戏操作。

通知文件放在作者控制的免费国内平台 [CNB 公告仓库](https://cnb.cool/longye-hub/epic7-notices)，启动检查不依赖 GitHub。普通公告不需要发布新版 APK：按递增编号发布，用户点“知道了”后只在本机保存已读状态，相同或更早公告不重复自动弹出。只缓存一条已校验的公开公告，离线缓存可能过时。

发现更高的内部版本号后，弹窗展示当前版本、新版本、测试渠道及修改说明，用户选择下载后由浏览器和系统完成安装。两种应用使用不同版本清单，避免下载错包。旧版没有更新检查能力，已安装旧版的人需要先手动覆盖安装本次版本，之后才能看到未来更新提醒。

