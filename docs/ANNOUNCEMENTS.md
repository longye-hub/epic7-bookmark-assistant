# 普通公告与国内通知源

两版共用公开通知读取模块，启动页提供自动检查、手动检查以及“查看最近公告（本机缓存）”。普通公告不依赖 APK 的版本号。

## 托管选择与费用边界

采用腾讯 CNB 公开仓库存放三个小型文本文件：`root.properties`、`mobile.properties`、`announcements.properties`。源码主仓库仍在 GitHub。只使用免费额度，不绑定付费预算、不启动云端构建或 AI 服务。

CNB 官方定价目前提供 100 GiB 仓库存储免费额度。平台政策可能变化，需定期复核；没有承诺永久免限额或全国所有运营商随时可达。发布者首次创建组织可能需实名认证；普通助手用户只匿名读取公开文件，无需平台账号。

官方资料：[定价](https://docs.cnb.cool/zh/pricing.html)、[OpenAPI](https://docs.cnb.cool/zh/develops/openapi.html)。正式通知源须在作者账号内创建、匿名读取验收后，再写入 `NoticeEndpoints.BASE` 并构建发布。不得把第三方仓库、临时预览地址或尚不存在的地址当成已部署成果。

腾讯 EdgeOne 的免费默认项目域名在中国大陆网络下有三小时预览链接限制，不适合作为无需购买域名的长期固定通知源；COS 可能按量收费，不符合本轮“只用免费托管”的选择。

## 发布普通公告

在通知仓库的 `announcements.properties` 编辑下面五个字段，UTF-8 无 BOM，每个值只写一行：

```text
schema=1
sequence=2026101401
active=true
title=助手公告
body=这里填写公开公告正文；无需发布新版 APK。
```

- `sequence` 为正整数。新公告必须使用更大的编号；建议使用日期加两位流水号。相同编号用于同一条公告，修改正文后想让已读用户再次收到，也要增加编号。
- `active=true` 才显示；撤回时改成 `false`，编号保持或增加。不要把编号改回零或较早编号来撤回已缓存的公告。
- 标题最多 80 个字符，正文最多 3000 个字符，只作纯文本显示。协议不接受操作指令、额外链接字段或脚本，不会启动刷新或购买。
- 用户点“知道了”后，仅本机保存最大已读编号；相同或更早公告不自动重复提醒。“稍后”不标为已读；已读公告可通过查看按钮重看。
- 应用只缓存最近一条校验通过的公开公告，后来的公告覆盖旧缓存。离线查看不代表公告仍有效；撤回会在下一次成功检查后生效。

## 发布版本更新

两版元数据格式及签名、哈希流程见 [UPDATING.md](UPDATING.md)。通知仓库和 GitHub 兼容清单都应更新，帮助旧版用户发现切换到国内源的新 APK。先公开安装包，核对正式下载链接与 SHA256，再发布清单。

国内通知源不等于国内安装包下载：当前安装包仍从作者 GitHub Release 下载，源码按钮也仍打开 GitHub。两者仅在用户主动点击时访问；启动检查不回退请求 GitHub。

## 隐私与失败处理

通知服务为不导出的普通 `:updates` 进程，属于代码隔离；同 UID 仍共享整个应用权限，不能宣称系统级隔离。只请求编译时固定的公开 HTTPS 文件，无正文、Cookie、授权令牌、设备标识、当前安装版本、截图或已读反馈。没有接入平台 SDK、统计 SDK、推送服务或用户注册。

平台与网络仍会获得 IP 等连接信息；托管方可能记录请求日志。公开公告缓存、最大已读编号和自动检查设置留在应用私有存储，不会发给通知服务。通知服务回传的也是公开文本。

公告和版本文件分别校验，一方失败不隐藏另一方的有效结果。拒绝重定向和格式无效内容，单文件最多 16 KiB。退出启动页会取消两个请求；检查失败可手动重试，不影响游戏交易引擎，也不会触发消费。
