# 隐私加固与更新入口 · Root v1.5.2 / Mobile v1.0.2

- 两版启动页新增当前版本、启动自动检查（每日最多一次，可关闭）、手动检查、源码仓库地址和访问按钮。发现新版显示版本和修改内容，用户通过浏览器下载并由安卓系统确认覆盖安装。
- 仅固定HTTPS GET本仓库各版本文件，不发送图片、余额、设备标识、当前版本、Cookie或正文；拒绝跳转、超大响应、错误应用类型及不属于作者仓库的下载地址。联网代码独立成私有更新进程，但网络权限仍属于整个应用，**不是系统级权限隔离**。
- Root版清理旧截图，每次截图及命令用完删除临时文件；保留防重复消费所需的私有待核验记录。
- 两版不再向系统logcat写运行余额等日志。手机版只在请求一帧时连接图像Surface；检查/任务结束、停止、离开游戏、锁屏、旋转或授权闲置后释放共享，再运行需重新授权。
- 保持包名和原签名，内部版本号Root14/手机版3。默认目标仍9999/9999/0；**刷新0仍可能购买当前商品**，初次检查使用手机版的只读画面检查。
- 沿用奥芙图标、动画、作者longye和QQ1513972923，以及非商业许可与第三方素材说明。

已完成构建、签名、同签名覆盖安装、公开安全规则测试及原完整离线回归；Android14模拟器只读画面检查成功且结束后共享已释放。手机真机与真实付费交易仍待验证。本发布继续标为测试版。

已经安装1.5.1/1.0.1等旧版的用户，需要先手动更新一次；之后才能使用应用内更新提醒。本次APK、使用说明、SHA256在Release附件。
