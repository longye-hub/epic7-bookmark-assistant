# 手机版 v1.0.5：修复首次横屏后反复要求授权

用户在竖屏启动页授权“共享整个屏幕”，返回横屏游戏后，旧版会误把正常方向切换当作运行中的尺寸异常，清空尚未使用的授权；再点开始又回到授权页。手机版 v1.0.5（内部版本6）保留首次切换时未使用的授权，并在实际请求画面时按当前横屏尺寸建立捕获。

- 任务或截图一旦开始，旋转仍会停止任务并释放共享；离开游戏、锁屏、授权闲置、检查结束和任务结束的释放规则保留。
- 悬浮面板就绪日志改为读取实际安装版本，避免旧的硬编码版本误导排查。识别模板、购买/刷新引擎、默认9999/9999/0和交易记录格式未改变；刷新0仍可能购买当前商品。
- 普通未Root安卓手机应下载“手机书签助手”。本页同时附原Root v1.5.4（内部版本16），文件与上次完全相同，仍需要su和实际1280×720画面，不包含本次手机修复。
- 两版均保留原包名和签名，停止任务后覆盖安装，不要先卸载或清除数据，不要删除待核验交易。
- 新增真实Service方向切换回归：旧编译产物复现失败，修复后8项断言通过。公开规则与完整离线图像、布局、交易、异常及动画回归通过；便携构建与发布手机APK的DEX和assets一致。Android14模拟器已覆盖安装，首次竖屏授权返回横屏商店后只读检查通过，随后共享正常释放；未刷新或购买。
- 更新和普通公告继续仅读取固定公开HTTPS信息，无用户数据上传或新权限。同UID进程是代码隔离，不是系统权限隔离。提醒在启动页触发并提供手动检查，没有后台推送。
