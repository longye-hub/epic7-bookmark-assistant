# 免费国内通知与普通公告 · Root v1.5.3 / Mobile v1.0.3

两版启动页现在可从作者的国内 CNB 通知仓库读取版本信息和普通公告，检查不依赖 GitHub 网络。普通公告无需发布新 APK，用户确认后只在本机保存已读编号；相同或更早公告不重复自动提醒，可查看最近一条本机缓存。

- 保留自动检查（每24小时最多一次，可关闭）、手动检查、当前版本与源码仓库入口；没有常驻后台推送或强制升级。
- 两份固定HTTPS公开文件分别读取，公告和版本的一方失败不隐藏另一方。拒绝跳转、异常协议、操作指令和单文件超过16KiB的内容；退出启动页同时取消请求。
- 不发送截图、余额、设备标识、当前安装版本、已读状态、Cookie、授权令牌或请求正文。通知模块属于共享UID下的代码隔离，联网权限仍属于整个应用；托管方及网络仍可获取IP等连接信息。没有接入平台SDK、统计或推送SDK。
- 公告源使用CNB免费仓库存储，不购买域名、不绑定付费预算、不启用云构建。普通用户无需平台注册；作者发布入口：https://cnb.cool/longye-hub/epic7-notices 。公告说明见源码docs/ANNOUNCEMENTS.md。
- 安装包下载与源码按钮仍指向作者GitHub仓库，仅在用户主动点击时访问。通知检查不回退到GitHub。
- 沿用包名和原签名，内部版本Root15/手机版4；默认目标仍9999/9999/0，刷新0仍可能购买当前商品。保留奥芙图标、动画、作者署名和非商业许可。

两版构建验签、原离线回归、新增公告/传输测试和实际公开CNB文件的生产请求与解析检查通过。本轮没有在线设备，未完成本版真机弹窗、缓存/已读状态的设备验收，也未进行真实刷新或购买；继续作为测试版发布。

旧用户需要先覆盖安装本次版本才能切换到独立公告源，不要先卸载。此前带更新检查的版本也可以从其GitHub版本清单发现本次新版。
